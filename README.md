# रामकुमार भंडार (Ramkumar Bhandar)
## दोहरी दुकान प्रबंधन, खाता बही एवं एआई टेलीफोन एजेंट प्रणाली

रामकुमार भंडार एक संपूर्ण, उत्पादन-उन्मुख (Production-Ready) दोहरी दुकान प्रबंधन और डिजिटल बहीखाता अनुप्रयोग है, जिसे विशेष रूप से श्री रामकुमार जी की आवश्यकताओं के अनुसार पूर्णतः हिंदी (देवनागरी) इंटरफेस में विकसित किया गया है।

---

## 1. मुख्य विशेषताएं (Key Features)

### 🌾 दोहरी स्वतंत्र दुकानें (Dual Independent Shops)
- **दुकान A**: बीज, खाद एवं दवाइयाँ (कृषि शाखा) - खाद बोरी, बीज पैकेट, कीटनाशक, बैच नंबर, एक्सपायरी डेट, स्टॉक इतिहास।
- **दुकान B**: किराना एवं जनरल स्टोर (किराना विंग) - घरेलू सामान, राशन, तेल-घी, मसाले, पैकेट।
- प्रत्येक दुकान का स्वतंत्र स्टॉक, लेन-देन, गल्ला हिसाब और दुकान खुलने/बंद होने की स्थिति।

### ⚡ एक-टैप दुकान स्थिति नियंत्रण (One-Tap Shop Status Toggle)
- मुख्य स्क्रीन पर दोनों दुकानों के बड़े कार्ड।
- 'दुकान बंद करें' / 'दुकान खोलें' का एक-टैप tactile टॉगल।
- सर्वर एवं एआई फोन एजेंट के साथ रीयल-टाइम सिंक्रनाइज़ेशन।

### 📖 सटीक खाता बही एवं लेखांकन इंजन (Accurate Khatabook Engine)
- **दशमलव-सुरक्षित अंकगणित (Decimal-Safe Arithmetic)**: जावास्क्रिप्ट के फ़्लोटिंग पॉइंट एरर से बचाव के लिए सभी वित्तीय मान आंतरिक रूप से पूर्णांक पैसों (Paise) में सुरक्षित रहते हैं।
- **कस्टमर क्रेडिट सेल (ग्राहक उधार)**: ग्राहक का बकाया बढ़ाता है, बिक्री राजस्व बढ़ाता है, नकद गल्ला अप्रभावित रहता है।
- **कस्टमर पेमेंट (जमा रसीद)**: ग्राहक का बकाया घटाता है, नकद जमा बढ़ाता है, दूसरी बिक्री नहीं बनाता।
- **सप्लायर उधारी खरीद**: सप्लायर का देना बढ़ाता है, इन्वेंटरी बढ़ाता है, बिना भुगतान नकद नहीं घटाता।
- **सप्लायर भुगतान**: सप्लायर का देना घटाता है, वास्तविक नकद भुगतान दर्ज करता है।
- **डुप्लिकेट रोकथाम (Idempotency Key)**: नेटवर्क स्लो होने पर दोबारा बटन दबाने पर डुप्लिकेट एंट्री की रोकथाम।
- **व्हाट्सऐप पर्ची शेयरिंग**: स्वचालित हिंदी संदेश के साथ सीधे ग्राहक के व्हाट्सऐप पर पर्ची भेजने की सुविधा।

### 🎙️ हिंदी आवाज़ प्रविष्टि (Hindi Voice Entry & Confirmation)
- बड़ा माइक्रोफोन बटन दबाकर स्वाभाविक हिंदी में बोलें:
  - *"रामलाल ने पाँच सौ रुपये जमा किए।"*
  - *"मोहन को एक हजार रुपये का उधार दिया।"*
  - *"आज दो बोरी खाद बेची।"*
  - *"दुकान बंद कर दो।"*
- देवनागरी अंक (५००), अंग्रेजी अंक (500) एवं हिंदी शब्द संख्याओं (पाँच सौ, एक हजार) की स्वचालित पहचान।
- **अनिवार्य पुष्टि स्क्रीन**: वित्तीय लेन-देन बिना मालिक की स्पष्ट सहमति के कभी भी स्वतः सहेजा नहीं जाता।

### 🤖 एआई टेलीफोन एजेंट एकीकरण (AI Phone Agent Integration)
- ग्राहक द्वारा फोन करने पर लाइव दुकान स्थिति (खुली/बंद) और समय की स्वचालित जानकारी।
- सप्लायर माल आगमन की घोषणा: मालिक सीधे बोलकर निर्देश दर्ज कर सकते हैं (जैसे: *"यूरिया का नया ट्रक कल सुबह 9 बजे पहुँचेगा"*), जिसे एआई कॉल करने वाले किसानों को बताता है।
- हाल की कॉलों का सारांश, ऑडियो रिकॉर्डिंग और वापस कॉल करने का अलर्ट।
- कॉलिंग सेवा और दुकान खुलने की स्थिति का स्वतंत्र प्रबंधन।

### 💾 बैकअप, रीस्टोर एवं डेटा निर्यात (Backups & Data Tools)
- एक-क्लिक JSON बैकअप डाउनलोड और सुरक्षित रीस्टोर।
- खाता बही और स्टॉक सूची का एक्सेल (UTF-8 BOM CSV) डाउनलोड।
- पूर्ण ऑफ़लाइन समर्थन (Local Storage, IndexedDB और Service Worker)।

## 3. ऐप चलाने का तरीका (How to Run Locally)

### 1. निर्भरताएं स्थापित करें:
```bash
npm install
```

### 2. एप्लिकेशन सर्वर प्रारंभ करें:
```bash
npm start
```
सर्वर `http://localhost:3000` पर चालू हो जाएगा।

### 3. ब्राउज़र में खोलें:
ब्राउज़र में `http://localhost:3000` पर जाएँ। ऐप तुरंत सभी सुविधाओं के साथ कार्य करने लगेगा।

## 5. एंड्रॉइड मोबाइल में इनस्टॉल करना (Android Deployment)

### विकल्प A: डायरेक्ट PWA इंस्टॉलेशन (तत्काल एवं सर्वश्रेष्ठ)
1. मोबाइल के Google Chrome ब्राउज़र में `http://<your-ip>:3000` खोलें।
2. Chrome मेनू (तीन बिंदु) में **"Add to Home screen" (होम स्क्रीन में जोड़ें) / "Install App"** पर टैप करें।
3. **रामकुमार भंडार** का मूल देशी ऐप आइकन आपके एंड्रॉइड फोन की होम स्क्रीन पर आ जाएगा। यह बिना इंटरनेट के भी पूरी तरह कार्य करेगा।

### विकल्प B: कैपेसिटर नेटिव APK बिल्ड
प्रोजेक्ट में `android/` फोल्डर पहले से तैयार है:
```bash
npx cap sync
npx cap open android
```
Android Studio में प्रोजेक्ट खुलने पर **Build > Build Bundle(s) / APK(s) > Build APK(s)** पर क्लिक करें।
*(नोट: इसके लिए सिस्टम में JDK 17+ और Android Studio का स्थापित होना आवश्यक है।)*

## 6. एआई टेलीफोनी सेवा कॉन्फ़िगरेशन (AI Telephony Setup)

### वेबहुक एंडपॉइंट्स:
- **लाइव स्थिति जांच**: `GET /api/ai-phone/status?shopId=krishi`
- **इनकमिंग कॉल वेबहुक**: `POST /api/ai-phone/webhook`
  - हेडर: `Authorization: demo_telephony_api_token_12345`
  - बॉडी:
    ```json
    {
      "CallerNumber": "+919826012345",
      "CustomerName": "राधेश्याम पाटीदार",
      "QueryText": "यूरिया खाद उपलब्ध है क्या और दुकान खुली है?",
      "ShopTarget": "krishi"
    }
    ```
- **प्रदाता सहायता**: Twilio, Exotel, Sarv, या किसी भी कस्टम AI Voice Calling Provider के साथ पूरी तरह अनुकूल।
